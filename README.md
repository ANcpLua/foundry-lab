# foundry-lab

C# and .NET labs for Microsoft Foundry agents and MCP tools.

- [Foundry IQ](foundry-lab/FoundryHostedAgents/responses/Hosted-FoundryIQ/README.md): configure a Foundry IQ-backed agent and invoke it from a C# console app.
- [Foundry MCP tools](foundry-lab/FoundryHostedAgents/responses/Hosted-FoundryMcpTools/README.md): use remote Microsoft Learn tools and a local inventory MCP server.

The samples target .NET 10. See each guide for setup and environment variables.
